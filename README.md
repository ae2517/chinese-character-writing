# 간화자 쓰기 연습 앱

교수가 오늘 배운 중국어 단어를 입력하면, 학생은 **획순 애니메이션 → 회색 글자 따라쓰기 → 빈칸 쓰기**로 연습하고,
획 하나하나에 **즉각 피드백**을 받습니다. 모든 시도는 교수 화면에 모이고 **엑셀(.xlsx)** 로 내려받을 수 있습니다.

* 학생 화면: `student.html`  /  교수 화면: `professor.html`  /  입구: `index.html`
* 서버를 직접 운영하지 않습니다. **GitHub Pages(화면) + Firebase Firestore(데이터 저장)** 조합이며 모두 무료 범위로 수업 규모에서 충분합니다.

---

## 1. 처음 한 번만: Firebase 준비 (약 10분)

Firebase 설정을 비워 두면 **데모 모드**(그 기기에만 저장)로 동작합니다. 실제 수업에서는 반드시 아래를 해 주세요.

1. <https://console.firebase.google.com> → **프로젝트 추가** (Google Analytics는 꺼도 됩니다)
2. **빌드 > Firestore Database > 데이터베이스 만들기**
   * 위치: `asia-northeast3 (서울)` 권장, 모드: **프로덕션 모드로 시작**
3. **빌드 > Authentication > 시작하기 > 로그인 방법 > 이메일/비밀번호 사용 설정**
   * **사용자 탭 > 사용자 추가**: 교수님 이메일과 비밀번호를 만듭니다. (교수 화면 로그인용, 이 계정만 데이터를 읽을 수 있습니다.)
4. **프로젝트 설정(톱니바퀴) > 일반 > 내 앱 > 웹 앱(`</>`) 추가** → 나오는 `firebaseConfig` 값을 `js/config.js` 의 `firebase:` 칸에 붙여 넣습니다.
5. **Firestore Database > 규칙** 탭에 `firestore.rules` 내용을 붙여 넣고, 안의 `PROFESSOR_EMAIL@example.com` 을 **3번에서 만든 교수 이메일**로 바꾼 뒤 **게시**합니다.
6. **Authentication > 설정 > 승인된 도메인 > 도메인 추가**: `내깃허브아이디.github.io`

> `apiKey` 등 Firebase 웹 설정값은 공개되어도 괜찮은 값입니다. 데이터 보호는 5번의 **규칙**이 담당합니다.

`js/config.js` 에서 함께 고칠 것: `targetRounds`(권장 반복 횟수, 기본 5), `guest`(체험용 계정 ID·비밀번호).

## 2. GitHub에 올리기 (npm + Vite 빌드, 자동 배포)

Firebase SDK 는 **npm(`firebase` 패키지)** 으로 설치하고 Vite 로 묶어서 배포합니다.

1. 새 저장소를 만들고 이 폴더를 push 합니다. (`node_modules`, `dist` 는 `.gitignore` 로 제외됨)
2. 저장소 **Settings > Pages > Build and deployment > Source: GitHub Actions** 로 바꿉니다.
3. `main` 에 push 하면 `.github/workflows/deploy.yml` 이 자동으로 빌드·배포합니다. (Actions 탭에서 진행 확인)
4. 주소
   * 학생: `https://내깃허브아이디.github.io/저장소이름/student.html`
   * 교수: `https://내깃허브아이디.github.io/저장소이름/professor.html`

내 컴퓨터에서 확인: `npm install` 후 `npm run dev` (빌드 확인: `npm run build` → `npm run preview`)

학생은 링크만 열면 되고, 처음 한 번 **회원가입**(연구 동의, 국적·성별·전공·학년·중국어/한자 학습 기간·한자 친숙도 1~5) 후 로그인합니다.

## 3. 수업에서 쓰는 법

**교수**
1. `professor.html` 로그인 → **① 단어 등록**
2. 과(예: `3과`)와 단어(여러 개는 줄바꿈)를 입력 → **병음·뜻 자동 생성** → 뜻을 확인·수정 → **저장**
   * 병음은 자동 생성(다음자는 문맥으로 판단), 뜻은 무료 기계번역이므로 **꼭 확인**하세요.
   * 획 데이터가 없는 글자는 경고가 표시되며 저장되지 않습니다.
3. **② 학습 데이터**: 시도별 기록, 필터, **엑셀 다운로드** / **③ 회차별 변화**: 1회차→5회차 평균 점수·시간 그래프, 학습자별 변화 / **④ 학생 목록**: 가입 정보, 비밀번호 초기화

**학생**: 과 선택 → 단어 선택 → ① 획순 애니메이션을 보며 따라쓰기 → ② 빈칸에 직접 쓰기 → 결과 확인 → 한 번 더. 🔊 버튼으로 언제든 발음을 다시 들을 수 있고, 매 회차 시작·채점 시 자동 재생됩니다.

단어는 과별로 계속 쌓이고, 학습 기록은 삭제되지 않고 계속 누적됩니다.

## 4. 채점 방식 (획 단위, 쓰는 즉시 판정)

정답은 오픈 데이터(Make Me a Hanzi / hanzi-writer-data)의 획 중심선입니다.

| 오류 | 판정 |
|---|---|
| 획순 | 지금 써야 할 획이 아닌 다른 획과 더 닮은 획을 먼저 씀 |
| 획수 | 정답 획수를 넘겨 씀(즉시) + 채점 때 모자란 획 |
| 획 시작 위치 | 시작점이 정답과 멀거나, 방향이 반대 |
| 자형 | 모양(굽음·꺾임) / 위치(치우침) / 크기(너무 길거나 짧음) / 어느 획과도 닮지 않음 |

* 점수: 획수·획순·시작위치 = `100×(1−오류수/총획수)`, 자형 = 획별 유사도 평균. **최종점수 = 가중평균**(기본 0.25/0.25/0.20/0.30, `config.js` 에서 변경). **시도마다** 계산·저장됩니다.
* 틀린 획은 쓰자마자 색(주황=순서/시작, 빨강=자형/획수)과 문장으로 알려 주고, 정답 획과 시작점을 잠깐 보여 줍니다. 학생은 `↩ 되돌리기`로 고쳐 쓸 수 있고, 되돌린 뒤에도 **최초에 쓴 오류는 기록**됩니다(고친 횟수는 `되돌리기횟수`).
* 채점이 너무 엄격/관대하면 `config.js` 의 `leniency` 를 조절하세요(1.0 엄격, **1.5 기본**, 2.0 매우 관대).
* 연습 횟수: 따라쓰기 1,2,3… 과 빈칸쓰기 1,2,3… 을 **각각** 세고(연습횟수(유형별)), 둘을 합친 **전체연습회차**도 따로 기록합니다. 회차는 학생 ID별로 서버에 저장되어 기기를 바꿔도 이어서 셉니다. 로그인 기록은 엑셀의 `로그인기록` 시트에 남습니다.

## 5. 엑셀 파일 구성

> 학생이 쓴 글씨 이미지는 시도마다 획 궤적으로 저장되며, 교수 화면 **② 학습 데이터**에서 `필기 > 보기`(정답 겹쳐 보기, PNG 저장) 또는 **필기 이미지 ZIP**(현재 필터의 PNG 일괄 다운로드)으로 받습니다. 파일명 끝 5자리가 엑셀의 `시도ID` 끝 5자리와 같습니다.

| 시트 | 내용 |
|---|---|
| 시도별_데이터 | 한 시도 = 한 행. 학습자ID, 학습날짜, 학습단어, 연습횟수, 획수/획순/획시작위치/자형 오류, 시도별 소요시간, 유형별 점수, 최종점수 + 국적·성별·전공·학년·학습기간·친숙도·연구동의 |
| 회차별_요약 | 과·단어·회차별 평균(변화 추이 확인용) |
| 획별_상세 | 시도 안 획 하나하나의 판정(분석을 더 깊게 하고 싶을 때) |
| 학습자_정보 | 가입 정보 |
| 변수설명 | 각 변수의 정의 |

## 6. 꼭 알아 두세요

* **연구 동의 문구**는 `js/student.js` 의 `renderConsent()` 에 있습니다. 동의하지 않은 학생도 학습은 가능하며 엑셀에 `비동의`로 표시되니 분석 시 제외하세요.
* **게스트 체험 계정**(기본 ID `guest` / 비밀번호 `guest1234`, `config.js` 에서 변경): 로그인 기록·학습 기록·진행 상황을 서버에 일절 저장하지 않으며, 규칙(`firestore.rules`)에서도 `guest` ID 의 쓰기를 거부합니다. 앱을 둘러보거나 리뷰할 사람에게 알려 주세요.
* **아이디/비밀번호 찾기**는 가입 때 입력한 전화번호로 합니다. 전화번호 원문은 저장하지 않고 해시만 보관하며, 문자 인증은 하지 않습니다(전화번호를 아는 사람은 해당 ID의 비밀번호를 재설정할 수 있음). 학생에게 본인 번호만 쓰도록 안내하세요.
* **비밀번호를 몇 번 틀려도 계정이 잠기지 않습니다**(Firebase 기본 로그인은 반복 실패 시 차단하므로 학생용은 별도 방식을 씁니다). 대신 이 방식은 수업용 간이 인증입니다: 비밀번호는 해시로 저장되지만, 학생 ID를 아는 사람이 해시를 조회할 수 있어 **다른 중요한 서비스의 비밀번호를 쓰지 않도록** 학생에게 안내하세요.
* 학습 기록은 학생이 **새로 쓰기만** 할 수 있고, 읽기·수정·삭제는 교수 계정만 가능합니다.
* 무료(Spark) 한도: 하루 읽기 5만 / 쓰기 2만 건. 한 시도 = 쓰기 2건이라 하루 약 1만 시도까지 괜찮습니다. 교수 화면은 새 기록만 추가로 읽어 읽기를 아낍니다.
* 발음 방식은 `js/config.js` 의 `ttsMode` 로 고릅니다(`online` 기본: 항상 인터넷 음성 / `auto`: 기기 음성 우선 / `device`: 기기 음성만). 기기 음성 사용 시에는 기기의 중국어 음성(TTS)을 쓰고, 기기에 중국어 음성이 없거나 브라우저가 지원하지 않으면(스마트폰·카카오톡 등 인앱 브라우저) 인터넷의 음성 파일(Google·Baidu TTS)로 자동 대체 재생합니다. 이 대체 서비스는 비공식이라 막히면 소리가 안 날 수 있습니다.
* 인터넷이 끊겨도 학생의 시도는 기기에 임시 저장되었다가 연결되면 자동 전송됩니다.
* 획 데이터와 라이브러리는 CDN(jsDelivr, cdnjs, gstatic)에서 불러오므로 인터넷이 필요합니다.

```bash
npm install
npm run dev
```

`config.js` 가 비어 있으면 데모 모드이며, 교수 로그인 비밀번호는 `demo` 입니다.
